# Inventario de datos reutilizados

## Objetivo

Dejar trazabilidad compacta de los principales conjuntos de datos usados por Madrid Refugio para la candidatura.

## Inventario resumido

| Conjunto | Fuente | Uso principal |
| --- | --- | --- |
| Modelo de alturas de edificación | Geoportal del Ayuntamiento de Madrid | Sombra proyectada por edificios |
| Arbolado viario detallado | datos.madrid.es | Sombra biológica y peso de tramo |
| Callejero oficial de Madrid | datos.madrid.es | Autocompletado y resolución de direcciones |
| Padrón municipal por edad | datos.madrid.es | Población vulnerable por barrio |
| Calidad del aire histórica | datos.madrid.es | Contexto ambiental e índice de confort |
| Estaciones de calidad del aire | datos.madrid.es | Georreferenciación e interpolación |
| Fuentes de agua potable | datos.madrid.es | Recursos de alivio próximos a ruta |
| Bibliotecas, centros culturales y polideportivos | datos.madrid.es | Refugios sustitutos operativos |
| Límites administrativos | Geoportal del Ayuntamiento de Madrid | Unidad territorial de análisis |
| Red peatonal urbana | OpenStreetMap | Base del routing peatonal |

## Nota metodológica

No existe un dataset municipal operativo y reutilizable de refugios climáticos oficiales con el nivel de detalle necesario para el motor. Por ello, el proyecto usa una capa de sustitución trazable basada en equipamientos municipales climatizados y georreferenciados.

## Recomendación de uso en candidatura

Este documento resume el inventario. La memoria principal y la página de metodología desarrollan el papel funcional de cada fuente dentro del sistema.
